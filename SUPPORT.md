# Support

For setup questions, start with [Setup and troubleshooting](docs/SETUP.md), [Configuration](docs/CONFIGURATION.md), and [Demo data](docs/DEMO_DATA.md).

For reproducible bugs or feature requests, use [GitHub Issues](https://github.com/adarshprakasan/Hospiq/issues). This project currently has no dedicated helpdesk, support SLA, or hosted service status page.

Include:

- Commit/version, operating system, Node/npm versions, and browser.
- Which role and screen/API route is affected.
- Minimal reproduction using fictional data, expected behavior, and actual behavior.
- Sanitized error text and whether automated checks pass.

Never include `.env` files, generated demo passwords, patient records, access tokens, or full database URLs. Use [SECURITY.md](SECURITY.md) for vulnerability reporting. For contribution conduct concerns, request a private maintainer channel without publishing sensitive details.
